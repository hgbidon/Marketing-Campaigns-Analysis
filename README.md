## 🧠 Overview  

This project analyzes a [marketing A/B testing dataset from Kaggle](https://www.kaggle.com/datasets/faviovaz/marketing-ab-testing) to **compare conversion rates between Ad and PSA groups**.

Using **Python** in a **Jupyter Notebook**, I performed data cleaning, statistical testing, and created visualizations to uncover actionable insights on **how ad exposure impacts user behavior**.

## 🚀 Key Steps  

### 1️⃣ Data Exploration & Cleaning  
- Grouped data by test group and ad exposure to compute **conversion rates**.  
- Conducted **summary statistics** and identified key behavioral patterns.

### 2️⃣ Statistical Analysis  
- Performed an **independent t-test** to evaluate conversion rate differences between **Ad** and **PSA** groups.

### 3️⃣ Visualization  
- Created **4 visualizations**: bar chart, histogram, countplot, and heatmap.  
- Applied **color-blind friendly palettes** for accessibility and clarity.  
👉 _Examples of visualizations are available in the repository for review._
